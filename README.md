# Buffett-Style Hybrid Scoring Engine

A hybrid investment scoring tool that applies Warren Buffett-style value investing principles to both traditional stocks (S&P 500) and DeFi protocols (via Chainlink-style data).

## Features

- Auto-scores companies based on key financial metrics
- Scores DeFi protocols using treasury, revenue, and governance data
- Mobile-ready Streamlit interface
- Ready for Chainlink Data Streams integration

## How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
